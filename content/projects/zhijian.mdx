## 为什么做纸间

我从 2021 年开始写文章。写完之后，还有一件绕不开的事：把内容整理成适合公众号阅读的样子。

纸间想处理的就是这一步。它不替我写，也不替我发布，而是把标题、正文、引用和列表放进统一的排版里，让我能边看边调整，最后复制到公众号。

## 现在能做什么

- **边写边看**：左侧编辑 Markdown，右侧实时预览，按接近手机阅读的宽度查看段落。
- **选样式，再微调**：提供「长文阅读」和「产品复盘」两套模板，可以调整字号、行距和主题色。
- **接着上次写**：正文和排版设置保存在当前浏览器里，刷新后可以继续；也支持 Markdown 文件导入、导出。
- **复制到公众号**：复制带格式的正文，手动粘贴到公众号编辑器，发布前再预览确认。

## 界面与用法

![纸间实际界面：左侧 Markdown 编辑，右侧文章排版预览](/images/projects/zhijian/workspace.png)

这张图是当前版本的真实截图，使用的是演示文章。

### 01 / 放入文章

把 Markdown 内容粘贴到左侧，或导入文件。用 `#`、`##` 标记标题，用 `>` 标记引用；不熟悉语法时，可以先看内置示例。

### 02 / 调整排版

选择模板，再按需要调整字号、行距和主题色。右侧同步显示效果，不必等复制出去才知道排成什么样。

### 03 / 复制到公众号

点击「复制富文本」，在公众号正文编辑区粘贴。文章标题、作者和封面仍需在公众号后台单独填写，发布前再检查一次预览。

## 这次是怎么做的

这是一次围绕具体写作环节的 Vibe Coding 实践。我来确定范围、界面方向和验收标准，Pi Agent 负责工具的代码实现，再根据实际使用反馈调整。

第一版先把编辑、预览和复制连起来。之后调整了界面的配色与层级：从绿色工具界面，到尝试深色工作台，最后回到白底、黑色点缀，让文章本身成为视觉中心。

验证时，我把示例文章实际粘贴进公众号编辑器，确认了这条流程可以使用。它还不是对所有文章格式的兼容性保证，但已经不只是一个静态页面。

## 先把一件小事做好

目前不做 AI 写作、账号系统和自动发布，也暂不加载图片与在线图表。先把文字排版这一步做顺，再根据真实文章的使用情况决定下一步。

文章保存在当前浏览器，不做云端同步。清理浏览器数据可能会丢失草稿，重要内容记得导出 Markdown 留一份。
