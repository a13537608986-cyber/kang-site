纸间是一款在浏览器里使用的公众号排版工具，适合习惯用 Markdown 写文章的人。把写好的内容放进来，就能预览标题、正文、引用和列表的排版，不用到公众号后台逐段调整格式。

编辑和预览放在同一个页面，改动会实时显示。排好后复制富文本，粘贴到公众号编辑器即可。

## 功能

- **实时预览**：左侧编辑 Markdown，右侧查看排版效果。
- **模板与样式**：内置「长文阅读」「产品复盘」两套模板，支持调整字号、行距和主题色。
- **文件导入导出**：导入已有的 Markdown 文章，也可以导出文件留作备份。
- **草稿自动保存**：保留当前浏览器里的正文和排版设置，下次打开可以接着编辑。
- **富文本复制**：复制带格式的正文，用于公众号排版。

![纸间的 Markdown 编辑与排版预览](/images/projects/zhijian/workspace.png)

## 开始使用

点击上方「去用一下」，无需安装或注册。粘贴或导入文章，选好模板，再根据预览调整样式。也可以先载入示例，看看不同排版的效果。

完成后点击「复制富文本」，到公众号正文编辑区粘贴。文章标题、作者和封面仍在公众号后台填写，发布前记得检查预览。

当前版本以文字排版为主，暂不支持图片和在线图表。草稿仅保存在当前浏览器，不跨设备同步，重要内容请导出备份。
