我从 2021 年开始写文章。写完了，还得收拾一遍格式：标题多大、段落隔多远、引用怎么放。内容已经写完，却还要在这些地方来回调整，有点烦。

纸间就是为这一步做的小工具。把 Markdown 放进来，选个样式，边看边调，最后复制到公众号。它不负责写文章，也不会帮你发布。

## 用起来很直接

打开就能用，不用注册。左边放文章，右边看效果，可以直接粘贴 Markdown，也可以导入文件。

目前有「长文阅读」和「产品复盘」两套模板。选好之后，字号、行距、主题色都能自己调。不知道从哪开始，可以先载入示例试试。

![纸间的 Markdown 编辑与排版预览](/images/projects/zhijian/workspace.png)

觉得合适了，点「复制富文本」，再粘贴到公众号正文里。标题、作者和封面还是在公众号后台填写。我已经拿示例文章试过这条流程，不过换成自己的文章，发布前还是看一遍预览比较稳妥。

## 也是一次 Vibe Coding 实践

我来定要做什么、界面怎么呈现，再让 Pi Agent 写代码，做出来之后自己试，不顺手的地方继续改。最后留下了现在这个白底工作台，编辑和预览放在一起，调整时不用来回切换。

这一版没有加 AI 写作，也暂不支持图片和在线图表。后面要补什么，等实际用着遇到问题再说。

正文和排版设置会保存在当前浏览器，刷新后还能接着写，但不会同步到其他设备。重要文章记得导出一份 Markdown，清理浏览器数据时别一起弄丢了。
