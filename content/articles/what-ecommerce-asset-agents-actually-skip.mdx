这周两家视频公司都发了 Agent。Runway Agent 一句话生成一条完整的广告，Luma Agents 说能从情绪板做到成片，还专门演示了电商素材的全流程。

我没有拿我们的商品去跑，只看了演示和说明。对着 Smart Photo 的流程，一段一段比。

## 我们的流程

Smart Photo 的流程大致是四段：准备商品图，生成场景图，运营筛图，出文案和视频。

筛图是一次出四张，运营挑一张。视频是设计同事在剪。这两段都要人，但都不是最费人的。

最费人力的是第一段，准备商品图。商品图进来要清洗，去水印、统一尺寸、清背景。这一段做不好，后面生成出来的都是废图。Smart Photo 最早那一年，可用率从三成做到七成多，有一部分功夫就花在这一段上。

## 全流程 Agent 接的是哪一段

全流程 Agent 演示的，主要是后面几段：给它素材和要求，它自己配场景，剪节奏，加字幕，出几个版本。这些在我们这里，对应的是运营筛图和设计同事剪视频，确实都能省。

它们没碰的是第一段。演示里的商品图都是现成的、干净的、拍好的。全流程 Agent 默认这一段已经解决了。

所以全流程这个词，对不同的人指的不是同一段。对已经有好素材的品牌，它接的是从素材到成片，确实是全流程。对我们这种上新快、商品图要自己准备的跨境卖家，它接的是后一半，而我们最费人的恰恰在前一半。

## 真正拦住的是价格

不过看完演示，让我觉得最不适用的，其实不是这一点，是价格。

这类工具是按生成量计费的。一条广告、一段视频，单看价格不贵。放到我们的量上就不一样了。Smart Photo 每月出几万张图，如果商品页上的视频也按这个量去做，按条计费加起来是一笔很大的钱。

这和当初 Smart Photo 选自建是同一笔账。外部工具的成本是线性的，用多少花多少；自建前期投入大，量上来以后越用越划算。电商素材的特点就是量大、单条价值低，按条计费的工具，天然不太适合。

## 能接，但不是现在

这不是说它们没用。后一半我们做得确实一般，视频尤其少，设计同事的时间有限。如果有一天价格降到按我们的量也划得来，接一个成熟的 Agent，比自己做划算。

但在那之前，前一半没人替，后一半又太贵。全流程 Agent 对我们来说，暂时还是一个演示。
