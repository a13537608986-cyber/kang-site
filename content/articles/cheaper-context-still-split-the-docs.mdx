这个月 Google 把 Gemini 3.1 Flash Lite 的价格压到了每百万 token 0.25 美元，带一百万上下文。3.1 Pro 更是到了两百万。一年前这个数字还要贵一个量级。

去年做内部知识问答的时候，我把 PRD 整篇放进 Dify，答得不对。后来按模块手动拆成三五百字一段，加上模板配置、模型参数这些标签，才答对。当时拆是被逼的，一篇文档放不进去，放进去也找不准。

现在放得进去了，也便宜了。第一反应是，那还拆什么，整篇扔进去让模型自己找。

想了想，不行。当时答错的原因，其实不是放不下。是文档里同一组词在不同地方指不同的东西：讨论中的方案、已经上线的做法、后来改过的规则，都叫一个名字。模型找到了相近的段落，但不知道哪一段是现在生效的。拆开加标签，解决的是这个，不是长度。

上下文长了，模型能同时看到所有版本。它未必更清楚哪个版本算数，只是更有可能把几个版本揉在一起答。

所以便宜下来的这部分，我更想花在别的地方。比如把拆好的模块多放几个进去，让它比较；或者把版本说明整篇带上，让它知道时间顺序。这些以前因为贵和放不下，没做。

上下文的价格是模型公司的事。文档里哪一句还算数，还是我们自己的事。
