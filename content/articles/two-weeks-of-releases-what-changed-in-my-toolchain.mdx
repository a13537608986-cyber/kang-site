这两周的发布密度，大概是今年最高的。9 月 2 日 Anthropic 发了 Claude Fable 5.1 和 Mythos 5.1，3 日 Google 发了 Gemini 3.8 Flash，4 日 OpenAI 发了 GPT-6 Astra，11 日 DeepSeek 发了 V4.1-Flash 还降了价，同一天 OpenAI 开了 Agents API 和全双工的 GPT-Live-1。中间还夹着一条，OpenAI 8 月底宣布终止和 Cursor 的合作，11 月生效。

我数了一下自己的工具链实际换掉的东西。一件：Claude Code 背后的模型升到了 5.1，这不是我换的，是它自己升的。

Astra 我试了，拿它做了一个很小的游戏 Demo，写过了。试完没有换成它，因为我的日常在 Claude Code 里，换模型等于换工具。

其他几个，看过说明，没有动。

这两周真正让我想了一下的，反而是 Cursor 那条。一个编码工具的模型供应商说不供了，工具要么换模型，要么自己训。用户没得选，只能跟着。我上个月画过自己的依赖图，这条新闻是那张图上第一次真的断了一根线，虽然断的不是我的。

所以两周四家发布，我的结论和春天看国内三家同一周发时一样：发布是它们的节奏，使用是我的。多了一条：靠谁，得知道。
