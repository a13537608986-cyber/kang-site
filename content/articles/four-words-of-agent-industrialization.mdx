这个月的行业盘点，把 Agent 工业化总结成四个词：原生电脑控制，工具调用，任务拆解，长链路执行。

我拿自己做过的几个东西对了一遍。

工具调用，用上了。纪要助手接飞书日历，就是让模型调一个创建日程的工具。接完我停了一步，但工具本身是接上的。

任务拆解，用上了一半。文案模块是生成一个模型、审校另一个模型，任务确实拆了。但拆的是我，不是模型。模型没有自己决定要拆成两步，是我把两步接起来的。

长链路执行，用上了。竞品监控每天跑，抓、整理、推，一条链自己走完。链不长，但每天走。

原生电脑控制，没用上。到今天为止，我做的东西里没有一个是让模型去点界面的。它们都在 API 后面，界面是给人的。

所以四个词，两个半。缺的那一个半，恰好是宣传里最热的。电脑控制和自主拆解，演示里都很好看，落到我这种内部工具上，还没有一个非用不可的理由。

工业化这个词我不反对。只是工业化的前提是有一批人天天在用，而不是一批人天天在演示。我们那两个半，是天天在用的。
