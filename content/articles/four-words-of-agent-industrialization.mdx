这个月的行业盘点，把 Agent 工业化总结成四个词：原生电脑控制，工具调用，任务拆解，长链路执行。

我觉得这个说法说早了。不是说这四件事没人在做，是工业化这三个字，要的是一批人天天在用，而我看到的，更多是一批人天天在演示。

我拿自己做过的几个东西对了一遍。

## 最像 Agent 的，是文案生成加审校

我做过的工具里，最像 Agent 的，是文案生成加审校。

一条商品文案，先按事实表生成，再交给另一个模型审，审不过就退回去自动重写，重写完再审，过了才到人手里。这一圈是它自己转的，中间不需要人插手。

它有任务拆解，写和审是分开的；它也有一条不算短的链路，生成、审校、退回、重写。实际跑下来，一条文案通常一两轮就过了。拆解是我设计的，不是模型自己决定的，但链路确实是它自己在走。

一两轮就过，说明事实表和规则写得还算清楚，生成的时候大部分问题已经避开了。审校真正退回的，多是合规和禁用词这一类。

## 工具调用和长链路，用上了

工具调用也用上了。纪要助手整理完会议，会去建飞书日程，建之前要人确认一下。那道确认，是它唯一需要人插手的地方，也是我最不打算拿掉的地方。

长链路执行，竞品监控算一个。它每天自己跑，抓页面，整理，推给我，不用我管。

它偶尔会抓取失败，通常是对方页面改了，抓不到东西，那天的摘要就不全。这种失败不会报警，要我自己发现，往往过几天才发现。这就是我看到的真实状态：链路是长了，可每一环都还需要有人偶尔去看一眼，它有没有断。

## 过几天才发现，就是不稳

竞品监控抓取失败，我往往过几天才发现。

过几天，意味着这几天的摘要都是缺的。缺了哪个产品、缺了哪几天，要回头一天天对。更麻烦的是，这几天里如果对方真有变化，我也跟着错过了。

一个工具偶尔失败，不算大事。大事是失败了没人知道。工业化说的是一批东西每天稳定地跑，出了问题有人马上知道、马上修。按这个标准，我的竞品监控连作坊都算不上，它是一个我偶尔想起来去看一眼的东西。

## 电脑控制，身边一个都没有

原生电脑控制，没用上。不只是我没用上，我身边也没有一个真正在跑的电脑操作 Agent。

演示很多。一个模型打开浏览器，填表，下单，看起来很顺。可在我们的工作里，还没有哪件事是非得让模型去点界面才能完成的。我们的工具都在接口后面，界面是给人的。

## 最缺的是稳定

要说工业化，最缺的是什么，我的答案是稳定。

四个词里没有稳定。原生电脑控制，工具调用，任务拆解，长链路执行，说的都是能做什么，没有一个说的是能不能每天都这样做。可工业化的意思，恰恰在后一半。

演示要的是一次成功，工业要的是一万次里失败几次、失败了怎么办。前一种看能力，后一种看工程。今年热闹的，大部分还在前一种。

我那条文案链路，一两轮就过，看起来挺顺。可如果问它一万条里有几条会在审校里转圈转不出来，出了问题会不会有人马上知道，我答不上来。答不上来，就还不是工业。

## 同事不关心 Agent 这个词

还有一个观察：身边的同事，对 Agent 这个词不关心。

他们关心的是事情有没有做完。文案有没有写好，图有没有出来，报表有没有发到群里。至于背后是一个 Agent，还是一个脚本，还是一个人，没人在意。

我自己也差不多。平时说起这几个工具，很少用 Agent 这个词，都是直接叫名字：纪要助手，竞品监控，文案模块。

这其实是一个挺好的信号。一个东西真正工业化以后，用的人是不会提它的名字的，就像没人会说今天用了电。现在大家还在谈 Agent，说明它还在被看见的阶段，还没有到被忘记的阶段。

## 两个半

所以四个词，我这里用上了两个半。那半个是长链路：链路是长了，可不稳。缺的那一个半，恰恰是宣传里最热的。

工业化这个词我不反对，只是觉得还没到。等哪天身边的同事不是在试电脑操作 Agent，而是离不开它了，那时候再说工业化，我会信。
