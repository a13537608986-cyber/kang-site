给伴侣做了一个小 App。功能很少：查天气，查公交什么时候到，查今天限不限行。打开就是这三样，没有别的。

## 出门前那几分钟

起因是每天出门前那几分钟。

要出门的时候，要看的东西就那几样：今天冷不冷、下不下雨，车几分钟到，开车的话限不限行。每一样都在一个不同的 App 里。打开要等，有的还先弹出别的东西，关掉，再找。几样看下来，时间都花在找上了。

这种烦每天都有，每天都不大，所以一直没人专门去解决它。

## 几个晚上，Claude Code

做这个东西花了几个晚上，用 Claude Code 写的。

技术上没什么难的。天气、公交、限行都有现成的数据可以接，界面就是三块。难的是另一件事。

## 难的是只放三样

难的是克制：只放三样，不加第四样。

做产品的习惯是往上加。做到一半，我想到好几个顺便也可以放进去的东西。每想到一个，就提醒自己一次：伴侣要的不是多，是不用找。多放一样，打开的时候就要多扫一眼，那个快就没了。

最后一样也没加。

## 三样用得差不多

给伴侣用了一段时间，三样用得差不多，没有哪一样特别多，也没有哪一样没人碰。

这个结果我挺满意。说明这三样选对了，都是出门前真要看的，没有一样是我以为有用、结果放在那里吃灰的。

反馈也不多，就是出门前打开看一眼，看完关掉。没有人说好用，也没有人提新需求。对这种东西来说，没有反馈就是最好的反馈。

## 最简单，也最稳

这大概是我做过最简单的东西，也是用得最稳的一个。它不需要增长，不需要留存，不需要版本计划，只需要明天早上打开还能用。

工作里做的东西，很难有这么干净的目标。做它的那几个晚上，让我想起最开始为什么想做产品。
