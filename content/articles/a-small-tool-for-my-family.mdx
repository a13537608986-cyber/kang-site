给伴侣做了一个小 App。功能很少：查天气，查公交什么时候到，查今天限不限行。打开就是这三样，没有别的。

## 出门前那几分钟

起因是出门前的那几分钟。

要出门的时候，要看的东西就那几样：今天冷不冷、下不下雨，车几分钟到，开车的话限不限行。每一样都在一个不同的 App 里。打开要等，有的还先弹出别的东西，关掉，再找。几样看下来，时间都花在找上了。

这种烦每天都有，每天都不大，所以一直没人专门去解决它。

## 几个晚上，Claude Code

做这个东西花了几个晚上，用 Claude Code 写的。

技术上没什么难的。天气、公交、限行都有现成的数据可以接，界面就是三块。难的是另一件事。

## 难的是只放三样

难的是克制：只放三样，不加第四样。

做产品的习惯是往上加。做到一半，我想到好几个顺便也可以放进去的东西。最想加的是空气质量，和天气放在一起很自然，数据也现成，加上去几乎不费事。

最后忍住了。

每想到一个，我就提醒自己一次：伴侣要的不是多，是不用找。空气质量有用，但不是每次出门都要看的。多放一样，打开的时候就要多扫一眼，那个快就没了。

这件事在工作里很少发生。工作里的需求往往是往上加的：有人提，有数据，有理由，很难说不。给伴侣做这个，没有人来提需求，加不加只有我自己决定，反而更需要给自己划一条线。

## 伴侣说挺好用

做好以后给伴侣用，第一反应是：挺好用。

我听到的时候挺高兴，因为这句话来得很直接。没有问能不能再加点什么，也没有说哪里不方便，就是打开，看了，说挺好用。

后来留意了一下，打开的时间不固定。没有一个准点。三样用得差不多，没有哪一样特别多，也没有哪一样没人碰。

这个结果我挺满意。说明这三样选对了，都是出门前真要看的，没有一样是我以为有用、结果放在那里吃灰的。也说明当时没加空气质量是对的，至少到现在，没有人问起它。

## 最简单，也最稳

这大概是我做过最简单的东西，也是用得最稳的一个。它不需要增长，不需要留存，不需要版本计划，只需要下一次打开还能用。

工作里做的东西，很难有这么干净的目标。做它的那几个晚上，让我想起最开始为什么想做产品：一个具体的人，一件具体的烦，做完以后，那个人说一句好用。
