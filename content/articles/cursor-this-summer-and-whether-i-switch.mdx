Cursor 这个夏天动作不断。6 月 SpaceX 宣布收购它，8 月 15 日正式完成，今天它又推出了自己的代码托管服务 Origin，说要替代 GitHub。

我不是 Cursor 的重度用户，平时用的是 Claude Code 和 Codex。但它这几步，我看得很仔细。

被收购，意味着它的方向以后不完全由它自己定。自建代码托管，意味着它不想把代码放在别人那里。这两件事放在一起，画出来的是一张依赖图：它靠别人的模型，靠别人的托管，现在想把能自己拿的都拿回来。

我看自己的工具链，也是一张依赖图。Claude Code 靠 Anthropic 的模型，Codex 靠 OpenAI 的，代码在 GitHub，部署在 Vercel。每一个都是别人的。哪一个变了，我的工作方式就得跟着变。

以前我不太想这件事，因为它们都好好的。Cursor 这个夏天让我想了一下：如果哪天其中一个出问题，我第二天怎么干活。

答案是，我没有备份。这不是今天要解决的事，但值得知道。

换不换 Cursor，不是我的问题。我的问题是，我的工具链里有没有一样东西是我自己的。现在看，只有代码。
